Свой модуль

use money подключает файл money.tb из той же папки. Функции модуля зовут через его имя. modpub делает функцию видимой другим файлам; без него (или с modpri) функция видна только своему файлу.

// файл money.tb
modpub func with_tax(price: int)
    return price + fee(price)

func fee(price: int)          // видна только внутри money.tb
    return price * 12 / 100

// файл main.tb
use money

func main()
    print(money.with_tax(1000))

Готовые библиотеки

С Tachbit идут библиотеки в папке lib/: ui (кнопки, поля, списки, окна внутри программы), physics (тела, столкновения, лучи), anim (плавность, ключи, кости). use ищет файл сначала рядом с программой, потом в папке TB_LIB, потом в ~/.tachbit/lib.

use anim

func main()
    count i from 0 to 4
        t = i * 0.25
        print(t, anim.ease("inout", t))
Вывод
0 0
0.25 0.0625
0.5 0.5
0.75 0.9375
1 1
Запомнить
  • В модуле не нужна main; tb check модуля проверит его функции.
  • Имя модуля = имя файла без .tb.
  • Новые возможности после заморозки ядра 1.2 появляются именно как библиотеки.
