Создать, взять, изменить

Список пишется в квадратных скобках. Номера идут с нуля. Пустой список создаётся с типом: list int, list text. Номер за краем списка останавливает программу с понятной ошибкой.

func main()
    nums = [3, 8, 1]
    print(nums[0], len(nums))
    nums[0] = 5
    nums.add(7)                     // в конец
    last = nums.pop()               // взять и убрать последний
    print(nums, last)

    names = list text               // пустой список текста
    names.add("Вали")
    names.add("Алия")
    sort(names)
    print(names)

    grid = list list int            // список списков
    grid.add([1, 2])
    grid.add([3, 4])
    print(grid[1][0])
    nums.clear()
    print(len(nums))
Вывод
3 3
[5, 8, 1] 7
[Алия, Вали]
3
0

Пройти и собрать итог

Чаще всего по списку идут через each, а нужен номер — через count.

func main()
    scores = [12, 40, 7, 33]
    total = 0
    best = scores[0]
    each s in scores
        total += s
        best = max(best, s)
    print("сумма", total, "лучший", best)
    count i from 0 to len(scores) - 1
        show(i, ":", scores[i], "  ")
    print("")
Вывод
сумма 92 лучший 40
0 : 12   1 : 40   2 : 7   3 : 33
Запомнить
  • Список передаётся в функцию как ярлык: функция меняет тот же список, а не копию.
  • sort сортирует числа и текст на месте.
  • .clear() делает список пустым и сразу отдаёт его память.
