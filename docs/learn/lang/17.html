Всё само

В Tachbit не нужно писать free. Память шага цикла и функции компилятор отдаёт сам, сразу. То, что живёт дольше, убирает уборщик памяти: он сам находит объекты, на которые больше никто не смотрит. Программа, которая работает неделями, не растёт по памяти.

func main()
    keep = dict int text
    count i from 1 to 300000
        order = "заказ №" + i + " на сумму " + (i % 1000)
        keep[i % 100] = order          // хранится только последние 100
    print(len(keep), keep[7])
Вывод
100 заказ №299907 на сумму 907

temp: временная память руками

Блок temp говорит: всё, что создано внутри, после блока не нужно. Память берётся большими кусками и отдаётся разом в конце — это очень быстро. Наружу можно вынести только числа.

func main()
    total = 0
    repeat 10 times
        temp
            lines = list text
            count i from 1 to 10000
                lines.add("строка " + i)
            each s in lines
                total += len(s)
    print(total)
Вывод
1088940
Запомнить
  • .clear() у списка и dict сразу отдаёт их память.
  • TB_GC_STATS=1 tb run файл.tb печатает каждую уборку; TB_GC=0 выключает уборщик.
  • Внутри temp нельзя return, fail, try.
ЗаданиеВозьмите пример с заказами и запустите его с TB_GC_STATS=1. Сколько было уборок? Потом поменяйте 100 на 100 000 и сравните.
