✱Указатели

if, else if, else

if проверяет условие. Если оно верно, выполняется блок под ним. else if — следующая проверка, если первая не прошла. else — всё остальное. Сравнения: == равно, != не равно, < > <= >=.

func grade(score: int)
    if score >= 90
        return "отлично"
    else if score >= 70
        return "хорошо"
    else if score >= 50
        return "сойдёт"
    else
        return "мало"

func main()
    print(grade(95), grade(72), grade(10))
Вывод
отлично хорошо мало

and, or, not

Условия соединяются словами: and — оба верны, or — хотя бы одно, not — наоборот. Скобки помогают читать сложные условия.

func main()
    age = 20
    money = 300
    banned = false
    if age >= 18 and money >= 100 and not banned
        print("можно купить")
    if money < 50 or banned
        print("нельзя")
    else
        print("денег хватает и не в бане")
    can = age >= 18 and not banned       // условие можно сохранить в bool
    print(can)
Вывод
можно купить
денег хватает и не в бане
true
Запомнить
  • После if не нужны ни скобки, ни двоеточие, ни then.
  • = кладёт значение, == сравнивает.
  • Текст тоже сравнивается: "a" < "b", name == "Алия".
ЗаданиеНапишите функцию ticket(age: int), которая возвращает цену билета: до 7 лет — 0, до 18 — 100, от 65 — 80, остальным — 200. Проверьте пять возрастов.
