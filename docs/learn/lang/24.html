Немедленное рисование

Библиотека ui написана на самом Tachbit. Каждый кадр программа заново зовёт ui.button, и функция сразу рисует кнопку и отвечает, нажали ли её. Хранить кнопки нигде не нужно. hbox/vbox раскладывают элементы без координат.

use ui

func main()
    try window_open(520, 300, "Заметки")
    u = ui.start()
    notes = list text
    draft = ""
    repeat while window_alive()
        ui.frame(u)
        clear_window(u.bg)
        ui.pad(u, 16)
        ui.heading(u, "Мои заметки")
        ui.hbox(u, 32, 8)
        draft = ui.edit(u, "draft", draft, "новая заметка")
        if ui.btn_main(u, "Добавить") and draft != ""
            notes.add(draft)
            draft = ""
        ui.done(u)
        each n in notes
            ui.lbl(u, "• " + n)
        ui.end_frame(u)
Проверка
tb check: ошибок нет. Откроется окно, поэтому запускайте у себя на компьютере.
Запомнить
  • Что есть: кнопки, галочки, поля ввода с выделением и буфером обмена, списки, прокрутка, меню, вкладки, ползунки, подсказки, перетаскивание, окна внутри программы, вопрос «да/нет», тёмная и светлая тема.
  • Пример большого приложения — файловый менеджер examples/apps/files.
ЗаданиеСделайте список дел: поле ввода, кнопка «Добавить», у каждой задачи галочка «сделано» и кнопка «удалить». Сохраняйте список в файл при выходе.
