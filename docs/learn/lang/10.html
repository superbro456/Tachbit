link на качество или элемент

link — это ярлык: другое имя для того же места в памяти. Изменили ярлык — изменилось само место. Удобно, когда до значения длинный путь.

obj Hero
    hp: int
    gold: int

func main()
    h = Hero(hp: 100, gold: 5)
    life: link h.hp
    life -= 30
    life += 5
    print(h.hp)

    xs = [1, 2, 3]
    first: link xs[0]
    first = 99
    print(xs)
Вывод
75
[99, 2, 3]

link в параметре

Если функция должна поменять число вызывающего, параметр делают ярлыком.

func heal(link hp, amount: int)
    hp += amount
    if hp > 100
        hp = 100

func main()
    hp = 70
    heal(hp, 50)
    print(hp)
Вывод
100
Запомнить
  • Пока жив ярлык на элемент списка, сам список нельзя растить (.add): память списка могла бы переехать. Компилятор это проверяет.
  • Ярлык на один элемент list bool взять нельзя: там биты, у бита нет адреса.
ЗаданиеНапишите swap(link a, link b), которая меняет два числа местами, и проверьте на двух переменных и на двух элементах списка.
