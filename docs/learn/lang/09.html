Описать и создать

obj описывает свой тип: какие у него качества и каких они типов. Создают его по имени типа, качества называют по имени. Пропущенные качества будут 0, пустым текстом или пустым списком.

obj User
    name: text
    age: int
    tags: list text

func main()
    u = User(name: "Алия", age: 20)
    u.age += 1
    u.tags.add("админ")
    print(u.name, u.age, u.tags)
    print(u)                          // obj печатается целиком

    team = list User
    team.add(u)
    team.add(User(name: "Вали", age: 17))
    each p in team
        if p.age >= 18
            print(p.name, "взрослый")
Вывод
Алия 21 [админ]
User(name: Алия, age: 21, tags: [админ])
Алия взрослый

obj — это ярлык

Переменная с obj указывает на сам объект. Если отдать его в функцию или положить во второе имя, меняется тот же объект.

obj Hero
    hp: int

func hit(h: Hero, dmg: int)
    h.hp -= dmg

func main()
    a = Hero(hp: 100)
    b = a                 // b и a — один и тот же герой
    hit(b, 30)
    print(a.hp)
Вывод
70
Запомнить
  • Тип объекта пишется с большой буквы (так принято).
  • obj можно класть в списки и dict, а качество может быть списком или другим obj.
  • Пустой (не созданный) объект при обращении останавливает программу с понятной ошибкой.
