Файлы

write_file записывает текст в файл целиком, read_file читает его. Обе могут сломаться (нет прав, нет файла), поэтому их зовут с try, or или else err.

func main()
    try write_file("notes.txt", "купить хлеб\nпозвонить маме\n")
    s = try read_file("notes.txt")
    each line in split(trim(s), "\n")
        print("•", line)
    print(file_exists("notes.txt"), file_size("notes.txt"))
    missing = read_file("нет-такого.txt") or "(пусто)"
    print(missing)
Вывод
• купить хлеб
• позвонить маме
true 50
(пусто)

Папки

Для папок: list_dir (имена, у папок / в конце), is_folder, make_folder, move (переместить или переименовать), remove (файл или пустая папка).

func main()
    try make_folder("box")
    try write_file("box/a.txt", "A")
    try move("box/a.txt", "box/b.txt")
    names = try list_dir("box")
    print(names, is_folder("box"))
    try remove("box/b.txt")
    try remove("box")
    print(file_exists("box"))
Вывод
[b.txt] true
false

Ввод, слова запуска, окружение

input() читает строку с клавиатуры (может сломаться, если ввод кончился). args() — список слов, написанных после имени файла: tb run main.tb один два. env("HOME") — переменная окружения. run("команда") запускает команду терминала и отдаёт код выхода. exit(код) завершает программу.

func main()
    show("Как тебя зовут? ")
    name = input() or "гость"
    print("Привет,", name)
    print("слов после файла:", len(args()))
    print(len(env("HOME")) > 0)
    code_out = run("true")
    print("код выхода:", code_out)
    exit(0)
Вывод (ввели: Алия)
Как тебя зовут? Привет, Алия
слов после файла: 0
true
код выхода: 0
Запомнить
  • Путь пишется от папки, где запустили программу, или полный: /Users/имя/….
  • \n в тексте — перевод строки, \t — табуляция, \" — кавычка.
