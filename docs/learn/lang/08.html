Параметры и return

У каждого параметра пишется тип. return отдаёт ответ и сразу выходит из функции. Тип ответа Tachbit узнаёт сам. При вызове можно назвать параметры по имени: тогда порядок не важен и код читается лучше.

func area(w: int, h: int)
    return w * h

func greet(name: text, n: int)
    repeat n times
        print("привет,", name)

func main()
    print(area(3, 4))
    print(area(h: 10, w: 2))         // по именам — в любом порядке
    greet("Алия", 2)
Вывод
12
20
привет, Алия
привет, Алия

Несколько ответов: gives

Если ответов несколько, их называют после gives. Внутри функции они — обычные переменные. Принять их можно сразу в несколько имён, в ячейки списка или в поля obj (p.x, p.y = f()).

func divide(a: int, b: int) gives whole: int, rest: int
    whole = a / b
    rest = a % b

func main()
    q, r = divide(17, 5)
    print("17 = 5 *", q, "+", r)
    res = [0, 0]
    res[0], res[1] = divide(9, 4)     // ответы сразу в ячейки списка
    print(res)
Вывод
17 = 5 * 3 + 2
[2, 1]

Функция зовёт сама себя

Это называется рекурсия. Нужна остановка, иначе функция будет звать себя вечно; Tachbit тогда скажет «стек переполнен».

func fact(n: int)
    if n <= 1
        return 1
    return n * fact(n - 1)

func main()
    print(fact(10))
Вывод
3628800
Запомнить
  • Один ответ — return; несколько — gives; не получилось — fail (урок 12).
  • Списки и obj приходят в функцию как ярлыки: изменения видны снаружи. Числа и текст копируются.
  • Порядок функций в файле не важен: main может стоять и первой.
