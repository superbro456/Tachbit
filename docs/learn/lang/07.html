Ключ и значение

dict хранит пары «ключ → значение». Ключ — text или int. Пустой словарь: dict text int (ключ текст, значение число).

func main()
    phones = {"Алия": "555-12", "Вали": "555-34"}
    print(phones["Алия"])
    phones["Тимур"] = "555-56"          // добавить или заменить
    print(phones.has("Вали"), phones.has("Олег"))
    phones.remove("Вали")
    print(len(phones), phones.keys())
    each name in phones                 // по ключам, в порядке добавления
        print(name, "→", phones[name])
Вывод
555-12
true false
2 [Алия, Тимур]
Алия → 555-12
Тимур → 555-56

Счётчик слов

Самый частый приём: посчитать, сколько раз встретилось каждое слово.

func main()
    text_in = "кот пёс кот мышь кот пёс"
    counts = dict text int
    each w in split(text_in, " ")
        if not counts.has(w)
            counts[w] = 0
        counts[w] += 1
    print(counts)
    print(counts.values())
Вывод
{кот: 3, пёс: 2, мышь: 1}
[3, 2, 1]
Запомнить
  • Взять ключ, которого нет, — ошибка; сначала проверьте .has(k).
  • Убирать ключи во время each по этому же словарю нельзя: компилятор не даст.
  • Порядок ключей при печати и each — как добавляли.
