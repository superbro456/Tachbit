Самая маленькая игра

window_open открывает окно. repeat while window_alive() — кадр за кадром: показывает нарисованное, принимает клавиши и держит частоту экрана. Точка (0, 0) — левый верхний угол, y растёт вниз. Цвет — rgb(красный, зелёный, синий) от 0 до 255.

func main()
    try window_open(400, 300, "Привет")
    x = 200.0
    repeat while window_alive()
        dt = frame_ms() / 1000            // секунды с прошлого кадра
        if key_down("left")
            x -= 200 * dt
        if key_down("right")
            x += 200 * dt
        clear_window(rgb(20, 20, 30))
        draw_rect(0, 250, 400, 50, rgb(60, 140, 80))
        draw_circle(round(x), 230, 20, rgb(47, 209, 191))
        draw_line(0, 0, mouse_x(), mouse_y(), rgba(255, 255, 255, 100))
        draw_text(10, 10, "Стрелки двигают круг", 1, rgb(255, 255, 255))
        if mouse_down()
            draw_pixel(mouse_x(), mouse_y(), rgb(255, 0, 0))
Проверка
tb check: ошибок нет. Откроется окно, поэтому запускайте у себя на компьютере.

Картинки, шрифты, ввод

Картинки PNG, JPEG, GIF и BMP: load_image → номер, draw_image. Шрифты TTF: load_font, draw_font, text_width. Набранные буквы — typed_text(), колёсико — mouse_wheel(), геймпад — pad_down и pad_axis.

func main()
    try window_open(640, 360, "Картинки")
    hero = load_image("hero.png") or -1
    font = load_font("/System/Library/Fonts/Helvetica.ttc") or -1
    name = ""
    repeat while window_alive()
        name += typed_text()
        clear_window(rgb(240, 240, 245))
        if hero >= 0
            draw_image(hero, 20, 20)
        if font >= 0
            draw_font(font, 20, 300, "Имя: " + name, 24, rgb(30, 30, 40))
        if pad_count() > 0 and pad_down(0, "a")
            draw_round(400, 40, 200, 80, 16, "all", rgb(255, 95, 162))
        set_cursor("hand")
Проверка
tb check: ошибок нет. Откроется окно, поэтому запускайте у себя на компьютере.
Запомнить
  • Клавиши: left right up down space enter escape backspace tab shift cmd ctrl alt, f1…f12, буквы и цифры. cmd = Command на Mac и Ctrl на Linux/Windows.
  • frame_ms() — длина прошлого кадра: умножайте скорость на него, и игра идёт одинаково при любой частоте.
  • Ещё: window_w/h, window_sharp (Retina), set_fps, fps, clipboard_get/set, blur_rect, draw_shadow, draw_image_alpha, image_scaled, screen_image.
