danger и память руками

Слова, которыми можно испортить память, работают только внутри блока danger. Так сразу видно опасные места. new_mem берёт блок байт (заполнен нулями), read/write 8/16/32/64 читают и пишут числа нужного размера, free_mem отдаёт блок.

func main()
    danger
        buf = try new_mem(64)
        write32(buf, 7)
        write32(buf + 4, 1000)
        fill_mem(buf + 8, 0xFF, 4)
        copy_mem(buf + 16, buf, 8)
        print(read32(buf + 16), read32(buf + 20), read8(buf + 9))
        buf = try grow_mem(buf, 128)
        free_mem(buf)
Вывод
7 1000 255

shape: раскладка байтов

shape описывает, какие поля лежат в памяти по порядку и какого они размера. Тип at адрес накладывает раскладку на память, и поля читаются как обычные int. Так описывают регистры устройств, заголовки пакетов и записи на диске.

shape Header
    kind: u8
    flags: bits 4
    ver: bits 4
    length: u16 big
    id: u32

func main()
    print(Header.size)
    danger
        a = try new_mem(Header.size)
        h = Header at a
        h.kind = 2
        h.ver = 3
        h.length = 513
        h.id = 70000
        print(h.kind, h.ver, h.length, h.id, read8(a + 2), read8(a + 3))
        free_mem(a)
Вывод
8
2 3 513 70000 2 1

zone: много кусков, одна уборка

Зона выдаёт куски памяти очень быстро и отдаёт их все сразу: удобно для кадра игры или одного запроса сервера.

func main()
    danger
        z = try zone_new(4096)
        count i from 1 to 100
            p = zone_take(z, 24)
            write64(p, i)
        print(zone_used(z))
        zone_clear(z)
        print(zone_used(z))
        zone_free(z)
Вывод
3200
0
Запомнить
  • Размеры полей: u8 u16 u32 u64, i8 … i64, bits N, bytes N, big — старший байт первым.
  • TB_MEM_CHECK=1 ловит чтение после free_mem, выход за край и забытые блоки — со строками.
  • Внутри danger числа при переполнении заворачиваются, как в железе.
