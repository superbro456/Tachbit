Ядро на Tachbit

tb bare файл.tb делает 64-битное ядро для x86-64: оно загружается само (QEMU или GRUB), без macOS и Linux. Внутри работают print, списки, obj, background (это настоящие задачи с переключением по таймеру). Функции с on timer, on keyboard, on interrupt N зовёт сам процессор.

shared ticks = int 0

func on_tick() on timer          // 1000 раз в секунду
    ticks += 1

func on_key() on keyboard        // при каждом нажатии
    k = read_key()

func main()
    print("ядро запущено")
    wait_ms(100)
    print("тиков:", ticks, "время:", uptime_ms())

Запуск

Нужен QEMU. Пример ядра — examples/kernel/main.tb, своя ОС Omnium — папка omnium/. tb app файл.tb собирает программу для Omnium (--own — своим машинным кодом, без LLVM).

brew install qemu                      # Mac, один раз
tb bare kernel.tb                      # → kernel.elf
qemu-system-x86_64 -kernel kernel.elf -serial stdio
./tools/kernel.sh examples/kernel/main.tb --text
./omnium/run.sh                        # своя ОС Omnium
Запомнить
  • Только в ядре: port_in/out, page_new/free, interrupts_on/off, uptime_ms, read_key, yield, module_*, kernel_symbol, call_address.
  • Падение задачи background в ядре роняет только её; a.crashed говорит, упала ли.
  • Проверено в QEMU; на настоящем компьютере пока не запускалось.
ЗаданиеЗапустите ./tools/kernel.sh examples/kernel/main.tb и найдите в коде, где ядро обрабатывает клавиши. Добавьте свою команду, которая печатает время работы ядра.
