Файл и запуск

Программа на Tachbit — это текстовый файл с расширением .tb. Работа начинается с функции main. Всё, что относится к функции, пишется ниже с отступом в 4 пробела. Отступ здесь не украшение, а часть языка: он показывает, где блок начинается и где кончается. Фигурных скобок, then и end в Tachbit нет.

// всё после двух косых черт — комментарий, компьютер его не читает
func main()
    print("Привет, Tachbit!")
    print("2 + 3 =", 2 + 3)       // print пишет через пробел и переводит строку
    show("без ")                 // show — то же, но без перевода строки
    show("перевода")
    print("")
Вывод
Привет, Tachbit!
2 + 3 = 5
без перевода

Команды терминала

tb run файл.tb собирает программу и сразу запускает. tb check файл.tb только ищет ошибки, ничего не запуская. tb build файл.tb кладёт готовую программу рядом с файлом. Полный список команд — в последнем уроке.

tb run hello.tb        # собрать и запустить
tb check hello.tb      # только проверить
tb build hello.tb      # сделать программу hello рядом с файлом
Запомнить
  • Одна программа — одна main в главном файле.
  • Отступ — ровно 4 пробела на уровень. Табы лучше не смешивать с пробелами.
  • Ошибки компилятор объясняет по-русски и с номером строки ещё до запуска.
