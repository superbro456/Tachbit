Четыре основных типа

Переменная — это имя для значения. Тип Tachbit узнаёт сам по первому значению. Типов четыре: int (целое число), dec (дробь), text (текст) и bool (true или false). Тип переменной потом не меняется: если в x лежит число, текст туда положить нельзя.

func main()
    age = 20                  // int
    price = 9.5               // dec
    name = "Алия"             // text
    vip = true                // bool
    print(name, age, price, vip)

    total = int 0             // тип можно написать явно
    rate = dec 0              // дробь, пока 0
    note = text               // пустой текст ""
    const SHOP = "Нектар"     // const — нельзя менять
    print(total, rate, note, SHOP)
Вывод
Алия 20 9.5 true
0 0  Нектар

Арифметика

Плюс, минус, умножение, деление и остаток %. У целых деление отбрасывает дробную часть: 7 / 2 даёт 3. Нужна дробь — пусть одно из чисел будет dec. Короткие записи +=, -=, *=, /= меняют переменную на месте.

func main()
    print(7 / 2, 7 % 2, 7.0 / 2)
    coins = 10
    coins += 5            // coins = coins + 5
    coins *= 2
    coins -= 1
    print(coins)
    print(2 + 3 * 4, (2 + 3) * 4)    // сначала * и /, потом + и -
Вывод
3 1 3.5
29
14 20
Запомнить
  • Имя переменной начинается с буквы; занятые слова (if, int, bool…) брать нельзя.
  • Слишком большое целое (больше 9 223 372 036 854 775 807) — ошибка с номером строки, а не тихая порча числа.
  • Имя внутри блока не может повторять имя снаружи: так нельзя случайно спрятать переменную.
ЗаданиеЗаведите переменные: цена товара, количество и скидка в процентах. Посчитайте сумму без скидки, размер скидки и итог. Итог посчитайте и в int, и в dec и сравните.
