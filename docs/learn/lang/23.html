Играть звуки

load_sound загружает WAV и отдаёт номер звука. play_sound играет один раз, loop_sound — по кругу; оба отдают номер голоса, которым потом управляют. play_tone(частота, мс) — простой писк.

func main()
    try window_open(300, 200, "Звук")
    step = try load_sound("step.wav")
    music = try load_sound("music.wav")
    m = loop_sound(music)
    sound_volume(m, 0.4)
    master_volume(0.8)
    repeat while window_alive()
        if key_down("space")
            v = play_sound(step)          // номер голоса
        if key_down("t")
            beep = play_tone(440, 150)
        if key_down("s")
            stop_sound(m)
        clear_window(rgb(30, 30, 40))
Проверка
tb check: ошибок нет. Откроется окно, поэтому запускайте у себя на компьютере.

Звук в мире

play_sound_at(звук, x, y, z) ставит звук в 3D: громкость по расстоянию, сторона, эффект Доплера. listener — где уши (обычно те же числа, что у camera). move_sound двигает звучащий голос.

func main()
    try window_open(300, 200, "3D-звук")
    car = try load_sound("engine.wav")
    v = loop_sound_at(car, -20, 0, 5)
    x = -20.0
    listener(0, 0, 0, 0, 0, 1)
    repeat while window_alive()
        x += 10 * frame_ms() / 1000
        move_sound(v, x, 0, 5)
        sound_pitch(v, 1.0)
        if not sound_playing(v)
            stop
        clear_window(rgb(30, 30, 40))
Проверка
tb check: ошибок нет. Откроется окно, поэтому запускайте у себя на компьютере.
Запомнить
  • Свой микшер: 64 голоса, без щелчков, ограничитель на выходе.
  • TB_SOUND_FILE=out.wav — писать звук в файл, TB_SOUND=0 — без звука.
ЗаданиеДобавьте звук в игру «лови звёзды»: писк при поимке, тон пониже при промахе и тихую музыку по кругу.
