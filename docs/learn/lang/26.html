В конце

✱Указатели

use c

Блок use c описывает функции C, которые хотите звать. Библиотеку называют в кавычках (use c "sqlite3") или берут свой файл .c. Без имени — стандартная библиотека C, вызов через c.. Вызов C — только в danger.

use c
    func abs(x: i32) gives i32
    func strlen(s: text) gives u64

func main()
    danger
        print(c.abs(-42), c.strlen("Tachbit"))
Вывод
42 7

for c, tb lib и syscall

Функция с for c видна из C под своим именем; tb lib файл.tb собирает libфайл.a и заголовок файл.h. syscall(номер, …) зовёт ядро Linux или Mac напрямую.

func add(a: int, b: int) for c
    return a + b

func main()
    danger
        pid = syscall(39)          // getpid на Linux x86-64 (на Mac номер другой)
        print(pid > 0)
    print(add(2, 3))
Вывод
true
5
Запомнить
  • Типы для C: int i8 i16 i32 i64 u8 u16 u32 u64 dec f32 bool text.
  • Текст из C сразу копируется в память Tachbit.
  • В своей ОС Omnium вместо syscall — каналы к службам.
ЗаданиеПодключите use c функцию getenv(name: text) gives text и сравните её ответ с env("HOME").
