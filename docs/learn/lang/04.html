✱Указатели

Четыре вида циклов

repeat N times — ровно N раз. repeat while условие — пока условие верно. count i from A to B — счётчик от A до B, оба конца входят. each x in список — по каждому элементу.

func main()
    repeat 3 times
        show("ура ")
    print("")

    n = 1
    repeat while n < 100
        n *= 3
    print("первая степень 3 после 100:", n)

    count i from 1 to 5
        show(i * i, " ")
    print("")

    each fruit in ["яблоко", "груша", "слива"]
        print("-", fruit)
Вывод
ура ура ура 
первая степень 3 после 100: 243
1  4  9  16  25  
- яблоко
- груша
- слива

skip и stop

skip — сразу к следующему шагу цикла. stop — выйти из цикла совсем.

func main()
    count i from 1 to 20
        if i % 2 == 0
            skip              // чётные пропускаем
        if i > 9
            stop              // дальше 9 не идём
        show(i, " ")
    print("")
Вывод
1  3  5  7  9
Запомнить
  • count умеет считать и вниз: count i from 5 to 1.
  • each работает со списками, текстом (по буквам), dict (по ключам) и каналами.
  • Бесконечный цикл: repeat while true, выход из него — stop или return.
