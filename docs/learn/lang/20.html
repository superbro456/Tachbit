by vec и by columns

each x in nums by vec складывает несколько чисел одной командой процессора (SIMD). obj … by columns хранит список объектов колонками: все x подряд, все mass подряд. Это быстрее, когда цикл читает одно-два качества из многих.

obj Particle by columns
    x: dec
    mass: dec

func main()
    nums = list int
    count i from 1 to 1000
        nums.add(i)
    total = 0
    each x in nums by vec
        total += x * x
    print(total)

    parts = list Particle
    count i from 1 to 100
        parts.add(Particle(x: i * 1.0, mass: 2.0))
    m = 0.0
    each p in parts
        m += p.mass
    print(m)
Вывод
333833500
200

Куски и together

each piece in data by N идёт кусками по N элементов, чтобы кусок помещался в быстрый кэш процессора; piece — окно в сам список. together просит память принести несколько значений одновременно, а не по очереди.

func main()
    data = list int
    count i from 1 to 10000
        data.add(i)
    sum = 0
    each piece in data by 4096
        each v in piece
            sum += v
    print(sum)

    ages = {"Алия": 20, "Вали": 17}
    together
        a = ages["Алия"]
        b = ages["Вали"]
        x = data[9999]
    print(a, b, x)
Вывод
50005000
20 17 10000
Запомнить
  • Эти слова не меняют смысл программы, только скорость. Сначала пишите просто, потом ускоряйте то, что медленно.
  • Многое компилятор делает сам: «заказ наперёд», горячие и холодные качества obj, склейка текста за один раз, list bool битами.
ЗаданиеЗамерьте time_ms сумму квадратов 10 000 000 чисел обычным each и с by vec.
