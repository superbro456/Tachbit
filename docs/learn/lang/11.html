enum

enum перечисляет все варианты. Значение пишется как Тип.вариант. print печатает имя варианта.

enum Status
    new
    paid
    sent

func main()
    s = Status.new
    print(s)
    s = Status.paid
    if s == Status.paid
        print("оплачен")
Вывод
new
оплачен

match

match разбирает значение по вариантам: у каждого свой блок. Несколько вариантов можно перечислить через запятую. Если вариант забыт, компилятор назовёт его по имени. match работает и с числами, и с текстом; там нужен else.

enum Status
    new
    paid
    sent

func label(s: Status)
    match s
        new
            return "новый"
        paid, sent
            return "в работе"
    return ""

func day_name(n: int)
    match n
        6, 7
            return "выходной"
        else
            return "будний"

func main()
    print(label(Status.new), label(Status.sent))
    print(day_name(3), day_name(7))
Вывод
новый в работе
будний выходной
Запомнить
  • match по enum должен разобрать все варианты или иметь else.
  • enum можно класть в obj, списки и посылать по каналам.
