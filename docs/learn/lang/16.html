Страница и JSON

http_get(адрес) отдаёт текст страницы. json_get(текст, путь) достаёт значение по пути: ключи и номера через точку. json_text(s) делает из текста строку JSON в кавычках, чтобы собрать свой JSON.

func main()
    j = "{\"users\": [{\"name\": \"Алия\", \"age\": 20}, {\"name\": \"Вали\"}]}"
    name = try json_get(j, "users.0.name")
    age = try json_get(j, "users.0.age")
    second = try json_get(j, "users.1")
    print(name, age)
    print(second)
    print("{\"msg\": " + json_text("он сказал \"да\"") + "}")
    // page = try http_get("https://example.com")   — нужен интернет
Вывод
Алия 20
{"name": "Вали"}
{"msg": "он сказал \"да\""}

Свой сервер и клиент

net_listen(порт) открывает сервер (0 — любой свободный, узнать какой: net_port). net_accept ждёт клиента. net_connect(адрес, порт) подключается. net_send и net_receive передают текст, net_close закрывает. Пустой ответ "" значит, что другая сторона закрыла связь.

func serve(srv: int)
    c = net_accept(srv) else err
        return -1
    msg = net_receive(c) else err
        return -1
    net_send(c, "эхо: " + msg) else err
        return -1
    net_close(c)
    return 0

func main()
    srv = try net_listen(0)
    port = net_port(srv)
    s = background serve(srv)
    c = try net_connect("127.0.0.1", port)
    try net_send(c, "привет")
    answer = try net_receive(c)
    print(answer)
    net_close(c)
    print(s.wait)
Вывод
эхо: привет
0
Запомнить
  • Все сетевые слова, кроме net_port и net_close, могут сломаться: нет сети, порт занят, сервер не ответил.
  • Чтобы сервер обслуживал многих, принимайте клиентов в цикле и отдавайте каждого в background (урок 18).
