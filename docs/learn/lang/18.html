background и .wait

background f(...) запускает функцию в отдельном потоке (на другом ядре процессора) и сразу отдаёт «номерок». .wait ждёт, пока функция закончит, и забирает ответ. Пока фон работает, main делает своё.

func sum_to(a: int, b: int)
    s = 0
    count i from a to b
        s += i
    return s

func main()
    x = background sum_to(1, 5000000)
    y = background sum_to(5000001, 10000000)
    z = sum_to(1, 10)                // main тем временем считает своё
    print(x.wait + y.wait, z)
Вывод
50000005000000 55

shared и lock

shared — переменная, общая для всей программы. Если её меняют из фона, это делают внутри lock имя: тогда в один момент блок выполняет только кто-то один, и сложения не теряются. unlock имя отпускает замок раньше конца блока.

shared hits = int 0

func work(n: int)
    repeat n times
        lock counter
            hits += 1
    return 0

func main()
    a = background work(100000)
    b = background work(100000)
    print(a.wait + b.wait, hits)
Вывод
0 200000
Запомнить
  • В background можно передать только int, dec, bool, text, каналы и списки через move.
  • Компилятор сам ловит: shared без замка, замок внутри того же замка, два замка в разном порядке.
  • a.crashed — упала ли задача (в своей ОС Omnium падение задачи не роняет систему).
ЗаданиеПосчитайте простые числа до 2 000 000 в четырёх background по кускам и сравните время (time_ms) с подсчётом в одном потоке.
