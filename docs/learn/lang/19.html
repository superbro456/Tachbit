В конце

✱Указатели

channel

Канал — очередь между потоками. .send(x) кладёт в конец, .receive() берёт из начала и ждёт, если пусто. .close() — больше писать не будут. each x in ch берёт, пока канал не закрыт и не пуст. .ready() — есть ли что взять без ожидания.

func worker(jobs: channel int, results: channel text)
    each n in jobs
        results.send("готово " + n * n)
    return 0

func main()
    jobs = channel int
    results = channel text
    w = background worker(jobs, results)
    count i from 1 to 3
        jobs.send(i)
    jobs.close()
    count i from 1 to 3
        print(results.receive())
    print(w.wait)
Вывод
готово 1
готово 4
готово 9
0

move и on all cores

move отдаёт список в фон целиком, без копии; после этого старое имя пустое. on all cores раздаёт цикл count или each всем ядрам процессора. Общий итог копят в shared через +=.

func total(xs: list int)
    s = 0
    each x in xs
        s += x
    return s

shared found = int 0

func is_prime(n: int)
    if n < 2
        return false
    d = 2
    repeat while d * d <= n
        if n % d == 0
            return false
        d += 1
    return true

func main()
    data = list int
    count i from 1 to 1000
        data.add(i)
    a = background total(move data)
    print(a.wait)
    count n from 1 to 100000 on all cores
        if is_prime(n)
            found += 1
    print(found)
Вывод
500500
9592
Запомнить
  • Внутри on all cores данные снаружи только читаются; компилятор следит даже через другие имена и функции.
  • TB_CORES=1 ./программа — запустить на одном ядре для сравнения.
  • По каналу идут int, dec, bool, text и enum.
