fail и три способа поймать

fail "причина" заканчивает функцию ошибкой. Такую функцию нельзя вызвать просто так: компилятор попросит решить, что делать при ошибке. or значение — подставить запасное. else err — свой блок, в err лежит текст причины. try — передать ошибку выше (в main программа остановится и напечатает причину).

func parse_age(s: text)
    n = to_int(s) or -1
    if n < 0
        fail "не число: " + s
    if n > 150
        fail "слишком много: " + s
    return n

func main()
    a = parse_age("20") or 0
    b = parse_age("сто") or 0            // запасное значение
    print(a, b)
    c = parse_age("200") else err
        print("ошибка:", err)
        c = 0
    print(c)
Вывод
20 0
ошибка: слишком много: 200
0

try внутри функции

try полезен, когда функция сама не знает, что делать с ошибкой, и отдаёт её тому, кто её вызвал.

func parse_age(s: text)
    n = to_int(s) or -1
    if n < 0
        fail "не число: " + s
    return n

func sum_ages(a: text, b: text)
    x = try parse_age(a)       // сломалось — sum_ages тоже ломается
    y = try parse_age(b)
    return x + y

func main()
    print(sum_ages("20", "30") or -1)
    r = sum_ages("20", "abc") else err
        print("не вышло:", err)
        return
    print(r)
Вывод
50
не вышло: не число: abc
Запомнить
  • Сломаться могут: read_file, write_file, input, to_int, to_dec, window_open, load_image, сеть и ваши функции с fail или try.
  • try можно и без присваивания: try write_file("a.txt", s).
  • Деление на ноль, номер за краем списка, переполнение — не fail, а авария: программа останавливается с номером строки.
ЗаданиеНапишите withdraw(balance: int, amount: int): ошибка, если сумма ≤ 0 или больше баланса, иначе новый баланс. Вызовите её тремя способами: с or, с else err и из другой функции через try.
