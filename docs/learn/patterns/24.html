Любые данные лежат в памяти. Обычно Tachbit сам решает, когда её освободить. Блок temp говорит прямо: всё, что тут создано, больше не нужно после блока.

В системном коде (драйверы, ядро) память берут вручную в блоке danger: new_mem — взять, free_mem — вернуть. Правило одно: у каждого куска есть хозяин, и хозяин обязан его вернуть ровно один раз. Забыли — утечка. Вернули дважды или пользуетесь после возврата — порча чужих данных.

Паттерн «Владение»

У каждого куска один хозяин. Взял — отдай ровно один раз.

ПриложениеОткрытые картинки и файлы закрывают, когда окно закрыли, иначе программа растёт часами.
ИграУровень загружают целиком в одну «зону» и выбрасывают целиком при переходе.
ОСOmnium считает память каждой клетки и не даёт одной программе съесть всю (квота 16 МБ).

Код

day24.tb
// день 24: память — кто владеет и когда отдать
func main()
    temp                                    // всё, что создано тут, уйдёт в конце блока
        words = split("раз два три", " ")
        print("слов:", len(words))
    danger                                  // руками: взял — отдай
        buf = new_mem(64) else err
            print(err)
            return
        write32(buf, 42)
        print("в памяти:", read32(buf))
        free_mem(buf)
Вывод
слов: 3
в памяти: 42
ЗаданиеВозьмите 16 байт, запишите четыре числа write32(buf + i*4, i) и прочитайте их обратно.
