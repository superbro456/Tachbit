В программе с окном есть два мира. Модель — данные: сколько нажали, какие задачи. Вид — картинка на экране. Правило: события меняют модель, а рисование только читает модель и ничего не меняет.

Так проще всего избежать ситуации «на экране одно, а в данных другое». Окно каждый кадр рисуется заново по модели, поэтому оно всегда честное. Библиотека lib/ui.tb работает именно так.

Паттерн «Модель / вид»

События меняют модель. Рисование только читает модель.

ПриложениеCRM: карточки в базе — модель, доска с колонками — вид. Перетащили карточку — поменяли статус в модели.
ИграМир игры — модель, кадр на экране — вид. Камеру можно двигать, мир от этого не меняется.
ОСОболочка рисует окна по списку окон в памяти; программа сама пикселей рабочего стола не трогает.

Код

day12.tb
// день 12: состояние отдельно, рисование отдельно
use ui

obj Model
    clicks: int

func main()
    try window_open(420, 240, "Счётчик")
    u = ui.start()
    m = Model()
    repeat while window_alive()
        ui.frame(u)
        // 1) событие меняет состояние
        if ui.button(u, 40, 120, 160, 44, "Нажми")
            m.clicks += 1
        if ui.button(u, 220, 120, 160, 44, "Сброс")
            m.clicks = 0
        // 2) рисование только читает состояние
        ui.big_text(u, 40, 40, "нажато: " + m.clicks, 3, rgb(240, 240, 240))
        ui.end_frame(u)
