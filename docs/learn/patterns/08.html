Искать в списке — значит перебирать всё подряд. Если записей тысячи, это медленно. Словарь (dict) находит запись по ключу сразу, как телефонная книга по имени.

Используйте словарь, когда вопрос звучит «дай мне X по такому-то имени/номеру». Перед чтением проверьте .has: ключа может не быть.

Паттерн «Справочник»

Если ищешь по ключу чаще одного раза — нужен словарь, а не перебор.

ПриложениеКлиент по номеру телефона, товар по артикулу, настройки по названию.
ИграТекстуры и звуки по имени, предметы инвентаря по коду, рекорды по игроку.
ОСПроцесс по номеру, файл по пути, драйвер по типу устройства.

Код

day08.tb
// день 8: справочник — найти по ключу сразу
func main()
    stock = dict text int
    stock["чай"] = 10
    stock["кофе"] = 4
    stock["чай"] -= 3
    if stock.has("сок")
        print("сок есть")
    else
        print("сока нет")
    each name in stock
        print(name, stock[name])
Вывод
сока нет
чай 7
кофе 4
ЗаданиеСделайте словарь цен и функцию, которая считает стоимость заказа ["чай", "кофе", "чай"].
