Почти вся игровая физика стоит на трёх числах. Позиция — где предмет. Скорость — насколько позиция меняется за секунду. Ускорение — насколько меняется скорость (тяжесть, толчок, тормоз).

Порядок в кадре всегда один: ускорение меняет скорость, скорость меняет позицию. Прыжок — это просто большая скорость вверх, а тяжесть сама вернёт героя на землю.

Паттерн «Интегратор»

скорость += ускорение × dt; позиция += скорость × dt.

ПриложениеПлавная прокрутка списка по инерции после свайпа — это скорость с трением.
ИграПрыжок, падение, полёт мяча, разгон машины, отдача от выстрела.
ОСКурсор мыши с ускорением: быстрое движение руки уводит курсор дальше.

Код

day16.tb
// день 16: позиция, скорость, ускорение
func main()
    y = 0.0          // высота мяча
    vy = 12.0        // скорость вверх
    g = -9.8         // тяжесть меняет скорость
    dt = 0.1
    t = 0.0
    repeat while y >= 0.0
        vy += g * dt         // ускорение меняет скорость
        y += vy * dt         // скорость меняет позицию
        t += dt
    print("мяч упал через", round(t * 10) / 10.0, "с")
Вывод
мяч упал через 2.4 с
ЗаданиеДобавьте отскок: когда мяч касается земли, скорость меняет знак и теряет 30%. Сколько отскоков до остановки?
