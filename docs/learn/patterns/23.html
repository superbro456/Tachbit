Когда две программы меняют одну переменную одновременно, возникает путаница. В Omnium части системы — это службы. У каждой свои данные, и никто их не трогает. Чтобы что-то попросить, службе посылают сообщение по каналу и ждут ответ.

В Tachbit для этого есть channel: send кладёт сообщение, receive забирает, each перебирает, пока канал не закроют. background запускает службу рядом с основной программой.

Паттерн «Служба»

Свои данные у каждого. Просьба — сообщение в канал. Ответ — сообщение обратно.

ПриложениеФронт и бэкенд сайта: страница посылает запрос, сервер отвечает. Это та же служба.
ИграОтдельный поток загружает уровни и посылает «готово» основному циклу.
ОСВ Omnium часы, клавиатура, консоль и диск — службы с каналами (omnium/clock.tb, keyboard.tb).

Код

day23.tb
// день 23: ОС — службы и сообщения вместо общих переменных
func clock_service(asks: channel text, answers: channel text)
    each q in asks                      // служба ждёт вопрос
        if q == "время"
            answers.send(date_now())
        else
            answers.send("не знаю: " + q)

func main()
    asks = channel text
    answers = channel text
    w = background clock_service(asks, answers)
    asks.send("время")
    print("ответ службы:", answers.receive())
    asks.close()
Вывод
ответ службы: 2026-11-22 12:30:00
