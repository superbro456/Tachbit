В игре одновременно живут десятки врагов, пуль, частиц. Их держат в списке и каждый кадр делают одно и то же: обновить всех, убрать «мёртвых», добавить новых.

Удалять из списка, по которому сейчас идёте, опасно: можно пропустить элемент. Надёжнее собрать новый список живых и заменить старый.

Паттерн «Список сущностей»

Обновить всех → собрать живых в новый список → заменить.

ПриложениеСписок уведомлений: каждое живёт 5 секунд, потом исчезает.
ИграПули, враги, искры, капли дождя.
ОСТаблица процессов: завершённые убирают, новые добавляют, остальным раздают время.

Код

day18.tb
// день 18: много сущностей — список, обновить всех, убрать мёртвых
obj Enemy
    x: dec
    hp: int

func main()
    enemies = list Enemy
    count i from 1 to 5
        enemies.add(Enemy(x: i * 10.0, hp: i))
    // выстрел по всем: каждый теряет 2 жизни
    each e in enemies
        e.hp -= 2
    // убрать мёртвых: собрать новый список живых
    alive = list Enemy
    each e in enemies
        if e.hp > 0
            alive.add(e)
    enemies = alive
    print("осталось врагов:", len(enemies))
Вывод
осталось врагов: 3
ЗаданиеКаждый «кадр» двигайте врагов на +5 по x и убирайте тех, кто ушёл дальше 40.
