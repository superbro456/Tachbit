Как устроена система

23Служба24Владение25Раздели и собери26Производитель / потребитель27Кольцо28По кругу29Проверка на входе30Состояние + события + цикл + слои

Один кладёт заказы, другой их готовит. Между ними канал — как окошко на кухне. Производитель не ждёт, пока блюдо будет готово, а потребитель не спрашивает каждую секунду «есть что-нибудь?» — он просто ждёт на канале.

Закрытие канала (close) — сигнал «заказов больше не будет». Цикл each по каналу сам закончится, когда всё прочитано.

Паттерн «Производитель / потребитель»

Между ними канал. Закрыл канал — значит работы больше нет.

ПриложениеОчередь отправки писем, обработка загруженных файлов, печать документов.
ИграЗагрузчик ресурсов кладёт готовые текстуры, игра забирает их между кадрами.
ОСКлавиатура кладёт нажатия, оболочка забирает. Диск кладёт прочитанные блоки, файловая система забирает.

Код

day26.tb
// день 26: производитель и потребитель
func cook(orders: channel int, ready: channel text)
    each n in orders
        ready.send("блюдо №" + n)
    ready.close()

func main()
    orders = channel int
    ready = channel text
    k = background cook(orders, ready)
    count i from 1 to 3
        orders.send(i)                     // производитель кладёт
    orders.close()
    each dish in ready                     // потребитель забирает
        print(dish)
Вывод
блюдо №1
блюдо №2
блюдо №3
