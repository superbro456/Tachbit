Когда мяч забивают, нужно: добавить очко, сыграть звук, показать надпись, записать статистику. Если физика мяча будет вызывать всё это сама, она станет знать обо всём на свете.

Вместо этого физика кладёт событие «гол» в очередь. Звук, счёт и надписи читают очередь и реагируют на то, что им интересно. Новую реакцию можно добавить, не трогая физику.

Паттерн «Очередь событий»

Источник только сообщает. Слушатели сами решают, что делать.

Приложение«Карточка перешла в Done» → уведомление, письмо клиенту, запись в журнал.
Игра«Враг побеждён» → очки, звук, выпадение предмета, достижение.
ОС«Флешка вставлена» → значок на столе, автоматическое сканирование, звук.

Код

day21.tb
// день 21: события — кто-то сообщил, другие отреагировали
obj Event
    kind: text
    power: int

func main()
    events = list Event                 // очередь событий кадра
    events.add(Event(kind: "удар", power: 7))
    events.add(Event(kind: "монета", power: 1))
    events.add(Event(kind: "удар", power: 2))
    score = 0
    each e in events                    // каждый слушатель смотрит своё
        if e.kind == "удар" and e.power > 5
            print("звук: громкий удар")
        if e.kind == "монета"
            score += 10
            print("звук: дзынь")
    print("очки:", score)
Вывод
звук: громкий удар
звук: дзынь
очки: 10
