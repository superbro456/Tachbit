Почти любой отчёт, счёт или статистика устроены одинаково: завели пустой итог, прошли по всем элементам, каждый добавили в итог. Это накопитель.

В одном проходе можно копить сразу несколько итогов. Главное — правильное начальное значение: для суммы 0, для счётчика 0, для минимума — что-то очень большое.

Паттерн «Накопитель»

Итог = начальное значение, затем один проход, каждый элемент меняет итог.

ПриложениеОтчёт за месяц: сумма продаж, лучший менеджер, сколько сделок больше 1000.
ИграИтоги уровня: сколько врагов побеждено, лучший комбо-удар, общее время.
ОССколько памяти занято всеми программами, какая программа ест больше всех.

Код

day03.tb
// день 3: повторение и «накопитель»
func main()
    scores = [12, 40, 7, 33, 25]
    total = 0
    best = 0
    many = 0
    each s in scores
        total += s               // сумма
        best = max(best, s)      // лучший
        if s >= 25
            many += 1            // счётчик по условию
    print("сумма", total, " лучший", best, " от 25 и выше:", many)
Вывод
сумма 117  лучший 40  от 25 и выше: 3
ЗаданиеДобавьте worst — самый маленький результат. Подумайте, с какого числа его начать.
