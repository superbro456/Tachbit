Безопасность — это не «спрятать кнопку», а проверить право на входе в действие. Каждая программа получает ключ со списком того, что ей разрешено. Функция камеры сама проверяет ключ и отказывает без него.

В Omnium нет «администратора, которому можно всё». Программа может только то, на что ей дали ключ-канал. Нет канала к диску — нет доступа к диску вообще.

Паттерн «Проверка на входе»

Право проверяет тот, кто выполняет действие, а не тот, кто показывает кнопку.

ПриложениеРоли в CRM: работник видит свои карточки, админ — все, деньги — только суперадмин.
ИграСервер проверяет каждый ход игрока, а не верит тому, что прислал клиент.
ОСКлючи Omnium: служба отвечает только тому, у кого есть её канал.

Код

day29.tb
// день 29: права — ключ проверяют на входе
obj Key
    owner: text
    can: list text

func allowed(k: Key, action: text) gives ok: bool
    ok = false
    each c in k.can
        if c == action
            ok = true

func open_camera(k: Key)
    if not allowed(k, "камера")
        fail k.owner + ": нет ключа на камеру"
    print(k.owner, "снимает")

func main()
    chat = Key(owner: "чат", can: ["сеть", "камера"])
    game = Key(owner: "игра", can: ["звук"])
    try open_camera(chat)
    open_camera(game) else err
        print("отказано:", err)
