Когда у вещи много свойств, держать их в отдельных переменных неудобно. Объявите тип: obj Player с полями. Теперь игрок — одна вещь, которую можно передать в функцию, положить в список, сохранить.

Хорошая модель — половина программы. Начинайте любой проект с вопроса: какие вещи есть в моём мире и что о каждой нужно помнить? Ответ превращается в obj.

Паттерн «Модель»

Каждая вещь из задачи — свой тип. Поля — только то, что действительно нужно помнить.

ПриложениеClient с именем, телефоном и списком заказов; Order с суммой и статусом.
ИграPlayer, Enemy, Bullet — у каждого позиция, скорость, жизни.
ОСTask с номером, состоянием и памятью; File с именем, размером и владельцем.

Код

day05.tb
// день 5: модель — свой тип для вещи из жизни
obj Player
    name: text
    hp: int
    items: list text

func main()
    p = Player(name: "Нази", hp: 100)
    p.items.add("меч")
    p.items.add("зелье")
    p.hp -= 30
    print(p.name, "здоровье", p.hp, "вещи", p.items)
Вывод
Нази здоровье 70 вещи [меч, зелье]
ЗаданиеОпишите obj Room (название, список игроков, максимум мест) и добавьте в комнату двух игроков.
