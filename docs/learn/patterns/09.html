Всё, что в переменных, исчезает при выходе. Чтобы помнить между запусками, программа читает данные из файла при старте и записывает при изменении. Это цикл загрузить → изменить → сохранить.

Два правила. Первое: при загрузке учитывайте, что файла может не быть (первый запуск). Второе: сохранение может сорваться — проверьте ошибку и скажите о ней.

Паттерн «Загрузить → изменить → сохранить»

Нет файла — начни с пустого. Ошибку записи никогда не молчи.

ПриложениеЗаметки, настройки, черновик письма, база клиентов.
ИграСохранение прогресса, рекорды, настройки звука.
ОСФайловая система делает то же для всех: журнал изменений, запись на диск, восстановление после сбоя.
