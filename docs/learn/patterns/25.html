У процессора несколько ядер. background запускает функцию на другом ядре, .wait ждёт её ответ. Лучше всего, когда каждый работник считает своё и ничего не делит.

Если общее всё же нужно, его объявляют shared и меняют только внутри lock. Замок пускает внутрь по одному. Tachbit проверяет это при сборке: менять shared без замка нельзя.

Паттерн «Раздели и собери»

Каждый работник — своя часть. Общее — shared и только под lock.

ПриложениеСжатие фото на всех ядрах, загрузка файлов, пока интерфейс остаётся живым.
ИграФизика на одном ядре, звук на другом, загрузка уровня на третьем.
ОСOmnium работает на нескольких ядрах сразу; общие данные ядра защищены замком.

Код

day25.tb
// день 25: параллельно — каждый своё, общее под замком
shared done = int 0

func work(a: int, b: int)
    sum = 0
    count i from a to b
        sum += i
    lock done
        done += 1                         // общее меняем только под замком
    return sum

func main()
    a = background work(1, 500000)
    b = background work(500001, 1000000)
    print("сумма:", a.wait + b.wait, " работ закончено:", done)
Вывод
сумма: 500000500000  работ закончено: 2
ЗаданиеРазделите сумму на 4 работника вместо двух и сравните время через time_ms() до и после.
