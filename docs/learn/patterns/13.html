Многие вещи живут в режимах: дверь закрыта, открыта или заперта. В каждом режиме допустимы свои действия. Запертую дверь нельзя открыть — сначала отпереть. Если описать это флажками is_open, is_locked, легко получить невозможное «открыта и заперта одновременно».

Конечный автомат решает это: один enum с режимами и одна функция «режим + действие → новый режим». Невозможные состояния просто нельзя записать.

Паттерн «Конечный автомат»

Один enum на режим, одна функция переходов. Никаких пар флажков.

ПриложениеЗаказ: новый → оплачен → отправлен → доставлен. Нельзя отправить неоплаченный.
ИграГерой: стоит, бежит, прыгает, падает. Из прыжка нельзя снова прыгнуть.
ОСЗадача: готова, работает, ждёт, завершена. Планировщик двигает её только по разрешённым стрелкам.

Код

day13.tb
// день 13: конечный автомат — в каком режиме и куда можно перейти
enum Door
    closed
    open
    locked

func next(d: Door, action: text) gives n: Door
    n = d
    match d
        closed
            if action == "открыть"
                n = Door.open
            else if action == "запереть"
                n = Door.locked
        open
            if action == "закрыть"
                n = Door.closed
        locked
            if action == "отпереть"
                n = Door.closed

func main()
    d = Door.closed
    each a in ["открыть", "запереть", "закрыть", "запереть", "открыть", "отпереть"]
        d = next(d, a)
        print(a, "→", d)
Вывод
открыть → open
запереть → open
закрыть → closed
запереть → locked
открыть → locked
отпереть → closed
ЗаданиеДобавьте режим broken: из любого режима действие «выбить» ломает дверь навсегда.
