Работу со списками почти всегда можно разбить на три кирпичика. Фильтр оставляет только нужные элементы. Преобразование (map) меняет каждый элемент по правилу. Свёртка (fold) превращает много элементов в одно значение.

Когда задача кажется сложной, спросите себя: что я отбираю, что я меняю, во что я сворачиваю? Ответы и есть три цикла. Их потом легко проверять по отдельности.

Паттерн «Фильтр → преобразование → свёртка»

Отбери, измени каждый, сверни в одно. Каждый шаг — отдельный цикл.

ПриложениеСчёт клиенту: отобрать неоплаченные услуги, к каждой добавить налог, сложить.
ИграВзрыв: отобрать врагов в радиусе, каждому посчитать урон, сложить очки.
ОСОтобрать процессы одного пользователя, взять у каждого память, сложить.

Код

day04.tb
// день 4: фильтр, преобразование, свёртка
func main()
    prices = [120, 900, 45, 300, 1500]
    cheap = list int
    each p in prices
        if p < 500
            cheap.add(p)                 // фильтр: оставить нужные
    with_tax = list int
    each p in cheap
        with_tax.add(p + p * 12 / 100)   // преобразование: каждый по правилу
    sum = 0
    each p in with_tax
        sum += p                         // свёртка: много в одно
    print(cheap, with_tax, sum)
Вывод
[120, 45, 300] [134, 50, 336] 520
ЗаданиеОтберите цены дороже 200, сделайте скидку 10% каждой и найдите самую большую.
