Меню, игра, пауза, конец — это режимы целой программы. Внутри каждого свои правила: в паузе мир не обновляется, в меню стрелки двигают выбор, а не героя.

Это тот же конечный автомат, что и дверь. Один match на режим, и каждый экран занимается только своим.

Паттерн «Автомат экранов»

Режим программы — один enum. Каждый экран обрабатывает только свои события.

ПриложениеМастер установки: шаг 1, 2, 3, готово. Вход: логин → код из SMS → главная.
ИграЗаставка → меню → уровень → пауза → проигрыш → меню.
ОСЗагрузка → вход → рабочий стол → блокировка экрана → выключение.

Код

day19.tb
// день 19: экраны игры — тот же автомат, что и дверь
enum Screen
    menu
    play
    pause
    over

func main()
    s = Screen.menu
    lives = 1
    each key in ["enter", "p", "p", "удар", "enter"]
        match s
            menu
                if key == "enter"
                    s = Screen.play
            play
                if key == "p"
                    s = Screen.pause
                else if key == "удар"
                    lives -= 1
                    if lives == 0
                        s = Screen.over
            pause
                if key == "p"
                    s = Screen.play
            over
                if key == "enter"
                    s = Screen.menu
        print(key, "→", s)
Вывод
enter → play
p → pause
p → play
удар → over
enter → menu
ЗаданиеДобавьте экран win: если в игре нажали «гол», перейти в него; из него enter ведёт в меню.
