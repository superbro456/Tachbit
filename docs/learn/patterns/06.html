Функция — это маленькая машина: на вход данные, на выход ответ. Если функция ничего не меняет вокруг и на одни и те же данные всегда даёт один ответ, её называют чистой. Её легко проверить: подал числа — сравнил ответ.

Делайте расчёты чистыми, а запись в файл, рисование и сеть держите в отдельных функциях. Тогда ошибку в расчёте можно найти без окна и без интернета.

Паттерн «Чистая функция»

Всё нужное — в параметрах, результат — через return, ничего вокруг не меняется.

ПриложениеРасчёт налога, скидки, срока — чистые функции. Сохранение в базу — отдельно.
ИграУрон по броне, расстояние между точками, следующая позиция — чистые функции.
ОСПеревод адреса памяти в номер страницы, проверка прав — чистые функции.

Код

day06.tb
// день 6: функции — вход, выход, без сюрпризов
func area(w: int, h: int)
    return w * h

func price_of(w: int, h: int, per_meter: int)
    return area(w, h) * per_meter

func main()
    print("ковёр 3×4 стоит", price_of(3, 4, 250))
Вывод
ковёр 3×4 стоит 3000
