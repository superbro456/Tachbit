Программа с окном или терминалом почти всё время ничего не делает — она ждёт событие: нажатие, строку, сообщение из сети. Пришло — разобрали, что это, ответили, снова ждём. Этот бесконечный круг называют циклом событий.

Внутри круга не должно быть долгих дел: пока вы считаете минуту, программа «зависла» для человека. Долгое отдают в фон (день 25).

Паттерн «Цикл событий»

Жди → разбери → ответь → снова жди. Внутри круга только быстрые дела.

ПриложениеКаждое приложение с окном: клик → обработчик → перерисовать → ждать дальше.
ИграТот же круг, только он не ждёт, а крутится 60 раз в секунду (день 15).
ОСЯдро ждёт прерывания: таймер, клавиатура, диск. Обработало — вернулось к ожиданию.

Код

day11.tb
// день 11: цикл событий — ждём, разбираем, отвечаем
func main()
    count_ok = 0
    repeat while true
        line = input() else err
            stop                          // ввод закончился
        cmd = trim(line)
        if cmd == "выход"
            stop
        else if cmd == "привет"
            print("и тебе привет")
            count_ok += 1
        else
            print("не знаю команду:", cmd)
    print("понял команд:", count_ok)
Вывод (ввели: привет / что / привет / выход)
и тебе привет
не знаю команду: что
и тебе привет
понял команд: 2
ЗаданиеДобавьте команды время (вывести date_now()) и счёт (сколько всего команд было).
