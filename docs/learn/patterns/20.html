Когда окно появляется мгновенно, это выглядит дёшево. Плавность — это движение от «было» к «стало» за время. Доля пути t идёт от 0 до 1, а lerp даёт точку между началом и концом.

Если t растёт ровно, движение механическое. Кривая ease делает его живым: быстро в начале и мягко в конце. Библиотека lib/anim.tb уже содержит эти функции.

Паттерн «Плавный переход»

Значение = lerp(было, стало, ease(t)). t идёт от 0 до 1 по времени.

ПриложениеВыезжающие панели, кнопки, которые «пружинят», переходы между страницами.
ИграКамера, которая догоняет героя; полоска жизни, которая плавно уменьшается.
ОСТема «Капля»: окна раскрываются и закрываются с мягкой кривой.

Код

day20.tb
// день 20: плавность — от «было» к «стало» за время
use anim

func main()
    from_x = 0.0
    to_x = 100.0
    count step from 0 to 5
        t = step / 5.0                          // 0 … 1 — доля пути
        a = anim.lerp(from_x, to_x, t)          // ровно
        b = anim.lerp(from_x, to_x, anim.ease("out", t))   // быстро, потом мягко
        print("t =", t, " ровно", round(a), " мягко", round(b))
Вывод

t = 0.2  ровно 20  мягко 49

t = 0.6  ровно 60  мягко 94
