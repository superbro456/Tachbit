Программа постоянно решает: можно или нельзя, туда или сюда. Новички пишут вложенные if в пять этажей, и логика теряется. Профессионалы делают наоборот: сначала проверяют всё, что может пойти не так, и сразу выходят. Это и есть охранник (guard).

После охранников остаётся «счастливый путь»: код, который работает, когда всё в порядке. Его легко читать, потому что он не спрятан внутри условий.

Паттерн «Охранник»

Плохие случаи проверяй первыми и выходи сразу. Хороший путь — последним, без вложенности.

ПриложениеВход на сайт: нет логина — выход; неверный пароль — выход; заблокирован — выход; дальше вход.
ИграПрыжок: герой в воздухе — нельзя; оглушён — нельзя; иначе прыгает.
ОСОткрыть файл: нет такого — ошибка; нет прав — ошибка; занят — ошибка; иначе открыть.

Код

day02.tb
// день 2: решения и «охранник»
func can_buy(money: int, price: int, age: int) gives ok: bool
    ok = false
    if age < 18
        return           // охранник: плохой случай уходит сразу
    if money < price
        return
    ok = true

func main()
    print(can_buy(500, 120, 20))
    print(can_buy(100, 120, 20))
    print(can_buy(500, 120, 15))
Вывод

false
false
