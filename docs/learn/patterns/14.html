Если каждое действие пользователя записать как объект «что сделали и с чем», получится команда. Команды можно сложить в список — это история. Взять последнюю и сделать наоборот — это отмена (Ctrl+Z).

Тот же приём даёт повтор действий, макросы и запись игры: достаточно сохранить список команд и проиграть его снова.

Паттерн «Команда»

Действие — это объект. История — список команд. Отмена — обратная команда.

ПриложениеОтмена в редакторе, журнал действий в CRM, «вернуть удалённое».
ИграПовтор матча, отмена хода в шахматах, запись ввода для проверки.
ОСЖурнал файловой системы: сначала записать, что собираемся сделать, потом делать — после сбоя можно доделать или откатить.

Код

day14.tb
// день 14: команды и отмена
obj Cmd
    kind: text      // "add" или "del"
    value: text

func do_cmd(doc: list text, c: Cmd)
    if c.kind == "add"
        doc.add(c.value)
    else
        last = doc.pop()

func undo(doc: list text, c: Cmd)
    if c.kind == "add"
        last = doc.pop()
    else
        doc.add(c.value)

func main()
    doc = list text
    done = list Cmd
    each w in ["раз", "два", "три"]
        c = Cmd(kind: "add", value: w)
        do_cmd(doc, c)
        done.add(c)
    print("было:", doc)
    undo(doc, done.pop())                 // Ctrl+Z
    undo(doc, done.pop())
    print("после двух отмен:", doc)
Вывод
было: [раз, два, три]
после двух отмен: [раз]
ЗаданиеСделайте «повтор» (Ctrl+Y): отменённые команды складывайте во второй список и умейте применить их снова.
