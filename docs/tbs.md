# Файлы .tbs — разметка и стили окна

В файле `.tbs` написано, **что** стоит в окне и **как выглядит**, а **что делает** программа — в `.tb`.
Читает `.tbs` библиотека `lib/view.tb` (`use view`), рисует `lib/ui.tb`. Сам язык для этого не менялся.

Вещь пишется как `obj`: вид, имя и место в скобках. Ниже, с отступом, идут свойства «ключ: значение».

```
btn save (A1:B2)
    text: Сохранить
    color: white
    backcolor: #3ad6c1
    corner.radius: 12
    corner.color: accent
```

## Где стоит вещь — в скобках

| Скобки | Что |
|---|---|
| `(B2)`, `(A1:C2)` | клетки сетки, как в Excel: столбцы `A B C ...` (до `Z`), строки `1 2 3 ...` |
| `(40, 120)` | точки от левого и верхнего края; размер — по содержимому |
| `(40, 120, 200, 36)` | точки и размер: x, y, ширина, высота |
| `(-20, -20)` | минус — от правого и нижнего края (кнопка в углу остаётся в углу, когда окно тянут) |
| `(50%, 10, 40%, 36)` | проценты — доля окна |
| `()` или без скобок | вещь сама встаёт в следующую свободную клетку: слева направо, сверху вниз |

## Сетка экрана

```
screen main 4x7          // экран main: 4 столбца, 7 строк
    cols: 200 * * 120    // ширина столбцов: число точек или * (делят остаток поровну); не написали — все *
    rows: 56 40 * * 52   // высота строк так же
    space: roomy         // расстояния: tight, normal (так по умолчанию), roomy
```

Если нужно точно: `gap: 12` (между клетками) и `pad: 20` (от края окна).

**Окно растягивают.** Клетки `*` растут и сжимаются вместе с окном, а места по точкам считаются заново в каждом кадре.
Если окно стало меньше, чем точные размеры `cols` и `rows` вместе, они сжимаются в одну долю, и за край ничего не уходит.
Длинный текст в узкой клетке кончается на «..». Вещь, которой совсем негде встать, просто не рисуется.

### Размеры столбцов и строк

| Запись | Что |
|---|---|
| `200` или `200px` | ровно 200 точек |
| `*` | делит остаток поровну с другими `*` |
| `200+` | как `*`, но не уже 200 точек (в CSS это `minmax(200px, 1fr)`) |
| `auto` (в `rows`) | высота по самой высокой вещи в строке (в CSS `auto`) |
| `cols: fill 170` | столько столбцов по 170 точек, сколько влезает; вещи сами текут по порядку (в CSS `repeat(auto-fill, ...)`) |

### Узкое окно — режим «как на телефоне»

Если окно уже 560 точек, сетка сама становится одним столбцом: вещи идут сверху вниз по порядку,
карточка — на всю ширину со своими вещами внутри, а колесо мыши листает (справа видна тонкая полоска).

| Свойство | Где | Что |
|---|---|---|
| `narrow: 700` | у экрана | с какой ширины окно считается узким (по умолчанию 560) |
| `narrow: off` | у экрана | никогда не перестраивать |
| `narrow: hide` | у вещи | в узком окне вещь прячется |
| `narrow: only` | у вещи | вещь видна только в узком окне |
| `order: 2` | у вещи | место в узком окне (меньше — выше); не написали — как в файле |
| `span: all` | у вещи | в потоке занимает всю ширину (заголовки, `area`, `line` и так всю) |

## Вещи

| Вид | Что | Свои свойства |
|---|---|---|
| `title` | крупный заголовок | `text` |
| `heading` | заголовок раздела | `text` |
| `subtitle` | подзаголовок | `text` |
| `text` | обычный текст | `text` |
| `note` | бледная пометка | `text` |
| `caps` | маленькая подпись ЗАГЛАВНЫМИ над полем | `text` |
| `code` | код моноширинным шрифтом | `text` |
| `chip` | цветная метка | `text` |
| `btn имя` | кнопка | `text`, `look: main / second / soft / ghost / danger` |
| `link имя` | текст-ссылка | `text` |
| `icon имя` | круглая кнопка-значок | `text: ×` |
| `field имя` | поле ввода | `hint` (подсказка), `value` (что написано сначала) |
| `area имя` | многострочное поле | `value` |
| `switch имя` | переключатель-«пилюля» | `text`, `on: yes` |
| `check имя` | галочка | `text`, `on: yes` |
| `slider имя` | ползунок | `min`, `max`, `value` |
| `pick имя` | выбор из списка | `items: Один \| Два \| Три`, `value: 1` (выбран второй) |
| `tabs имя` | вкладки | `items`, `value` |
| `card` | карточка-фон: вещи в её клетках отходят от краёв | `padding` |
| `line` | черта | |
| `image` | картинка | `src`, `fit` |

Имя нужно вещам, на которые нажимают или в которые пишут: по нему программа узнаёт нажатие и текст.

## Общие свойства (как в CSS)

Можно писать наши имена или имена из CSS: справа — то же самое по-CSS-ному. Размеры — в точках (`12` или `12px`) или в процентах.

| Свойство | CSS | Что |
|---|---|---|
| `text` | текст тега | надпись |
| `color` | `color` | цвет текста |
| `backcolor` | `background`, `background-color` | цвет фона |
| `corner.radius` | `border-radius` | скругление краёв |
| `corner.color` | `border-color` | цвет рамки |
| `corner.width` | `border-width` | толщина рамки (0 — без рамки) |
| `width`, `height` | `width`, `height` | своя ширина и высота (точки или % места) |
| `min.width`, `max.width`, `min.height`, `max.height` | `min-width` ... | не меньше и не больше |
| `scale` | `transform: scale` | вся вещь крупнее или мельче: `1.5` или `150%` |
| `margin` | `margin` | отступ снаружи: `8` или `8 16` (сверху-снизу, слева-справа) |
| `padding` | `padding` | отступ внутри (текст от краёв; у `card` — вещи от краёв карточки) |
| `size` | `font-size` | размер букв |
| `font` | `font-weight`, `font-family` | `regular`, `bold`, `serif` (с засечками), `mono` (код), `display` (заголовки), шрифт системы по имени (`Georgia`, `Arial`), файл `fonts/My.ttf`, список `Georgia, serif` — берётся первый, что нашёлся |
| `align` | `text-align` | `left`, `center`, `right` |
| `spacing` | `letter-spacing` | разрядка между буквами |
| `line.height` | `line-height` | высота строки: `1.5` или `150%` |
| `transform` | `text-transform` | `upper`, `lower`, `capitalize` |
| `decoration` | `text-decoration` | `underline`, `line-through` |
| `wrap` | `white-space` | `yes` — длинный текст переносится по словам (абзац) |
| `opacity` | `opacity` | прозрачность: `0.5` или `50%` |
| `shadow` | `box-shadow` | тень: `none`, `small`, `medium`, `big` |
| `visible` | `display: none`, `visibility: hidden` | `no` — вещь спрятана |
| `layer` | `z-index` | слой: больше — выше |
| `cursor` | `cursor` | курсор над вещью: `hand`, `text`, `move` |
| `tip` | `title` | подсказка, если задержать мышь |
| `disabled` | `disabled` | `yes` — кнопку не нажать (серая) |
| `hover.color`, `hover.backcolor`, `hover.corner.color` ... | `:hover { ... }` | любое свойство с `hover.` — когда мышь над вещью |
| `look` | — | вид кнопки: `main`, `second`, `soft`, `ghost`, `danger` |
| `accent` | `accent-color` | цветное у поля, ползунка, переключателя |
| `style` | `class` | взять свойства из стиля |

Цвета: имена темы — `accent ink dim red panel bg raised field line faint white black` (они сами меняются в светлой теме),
имена из CSS — `green blue yellow orange purple pink gray transparent`, и `#ff8800`, `#f80`, `rgb(255, 136, 0)`.

Картинка: `image (A1:B3)` и `src: cat.png` (путь от программы или от папки файла .tbs). Вписывается в место целиком;
`fit: fill` — растянуть на всё место.

## Стекло — вид по умолчанию

Каждый экран .tbs сам рисуется стеклом: на фоне картинка (`lib/back/glass.jpg`), карточки полупрозрачные
и размывают то, что под ними, поля и кнопки тоже полупрозрачные. Свой фон — `backimage` или `backcolor` у экрана.

| У экрана | Что |
|---|---|
| `theme: solid` | обычный сплошной тёмный вид, без стекла |
| `theme: glass` | стекло (так по умолчанию) |

Значения по умолчанию (как на экране `glass` в примере). Что напишешь сам — важнее:

| Вещь | По умолчанию |
|---|---|
| фон экрана | `lib/back/glass.jpg`, `backdim: 15%` |
| `card` | `backcolor: rgba(255, 255, 255, 0.12)`, `corner.color: rgba(255, 255, 255, 0.35)`, `corner.radius: 22`, `blur: 18`, `padding: 24`, без тени |
| `btn` с `look: main` | `backcolor: gradient(to right, #3ad6c1, #6b5bff)`, `glow: #6b5bff`, белый текст |
| другие `btn` | полупрозрачные, `transition: 200` |
| `field`, `area` | тёмное стекло, `corner.color: rgba(255, 255, 255, 0.3)` |
| `title`, `heading` | `text.shadow: yes` |
В программе без .tbs стекло включает `ui.glass(u)`, а картинку фона даёт `ui.glass_image(u)`.

**Своё стекло для всего файла.** Стиль с именем вида меняет все такие вещи сразу, без `style:` у каждой:

```
style card
    backcolor: rgba(255, 255, 255, 0.2)
    blur: 30
    corner.radius: 16

style btn
    glow: none
```

## Фон, стекло и прочая красота

| Свойство | CSS | Где | Что |
|---|---|---|---|
| `backimage: sky.jpg` | `background-image: url(sky.jpg)` | экран, `card`, любая вещь | картинка на фоне |
| `backfit: cover` | `background-size` | там же | `cover` — заполнить всё (у экрана так по умолчанию), `contain` — вписать целиком, `fill` — растянуть, `center` — как есть |
| `backblur: 12` | `filter: blur(12px)` | экран | размыть фон-картинку |
| `backdim: 30%` | — | экран, `card` | затемнить фон (текст поверх читается лучше) |
| `blur: 18` | `backdrop-filter: blur(18px)` | любая вещь | размыть то, что под вещью: матовое стекло |
| `backcolor: rgba(255, 255, 255, 0.12)` | так же | любая вещь | полупрозрачный цвет; ещё `#ffffff20` и `transparent` |
| `backcolor: gradient(#3ad6c1, #6b5bff)` | `linear-gradient(...)` | экран, `card`, `btn` | градиент сверху вниз; `gradient(to right, a, b, c)` — слева направо, цветов сколько угодно |
| `glow: accent` | `box-shadow: 0 0 18px цвет` | любая вещь | цветное свечение вокруг |
| `text.shadow: yes` | `text-shadow` | текст | тень у букв (`yes` — тёмная, или свой цвет) |
| `transition: 200` | `transition` | любая вещь | `hover.*` цвета меняются плавно, а не сразу |
| `opacity: 60%` | `opacity` | любая вещь | теперь настоящая прозрачность: сквозь вещь видно картинку |

Свойства фона экрана пишутся сразу под `screen`, как `cols` и `rows`:

```
screen glass 3x4
    backimage: sky.jpg
    backdim: 15%
    card login (A2:B4)
        backcolor: rgba(255, 255, 255, 0.12)
        corner.color: rgba(255, 255, 255, 0.35)
        blur: 18
    btn go (A4:B4)
        text: Войти
        backcolor: gradient(to right, #3ad6c1, #6b5bff)
        glow: #6b5bff
```

Весь пример — экран `glass` в `examples/apps/tbs_demo/app.tbs` (`TBS_PAGE=glass tb run examples/apps/tbs_demo/main.tb`).

## Стили

Это как классы в CSS: стиль пишется один раз, а вещь берёт его через `style:`. Её собственные свойства важнее свойств стиля.

```
style price
    color: accent
    size: 22
    align: right

screen main 2x2
    text total (B2)
        text: Итого: 0 сом
        style: price
```

### Взять у другой вещи: from

`from: имя` — вещь берёт все свойства у другой вещи (с любого экрана), а ты пишешь только то, что меняешь:

```
card a (A1)
    backcolor: gradient(#ff6ea0, #6b5bff)
    corner.radius: 26
card b (B1)
    from: a
    corner.radius: 6        // всё как у a, только углы другие
```

Стиль тоже можно сделать из другого стиля: `style tile_blue from tile`.

### Свой вид вещи — как obj в .tb

Родителя пишешь один раз, а потом ставишь его как обычную вещь и сверху меняешь, что нужно:

```
style pill from btn                 // pill — это кнопка с такими свойствами
    backcolor: gradient(to right, #3ad6c1, #6b5bff)
    corner.radius: 18
    glow: #6b5bff

screen main 3x2
    pill save (A1)
        text: Сохранить
    pill send (B1)
        text: Отправить
        backcolor: gradient(to right, #ff6ea0, #ffa06e)   // своё поверх родителя
```

Стиль-родитель пиши в файле выше экранов, где он стоит.

### Откуда вещь берёт свойство

Без каскада CSS и без `!important`: свойство берётся из первого места, где оно написано.

1. Свойства под самой вещью.
2. Вещь из `from:` (и её `from:`, если есть).
3. Родитель (`pill save` берёт из `style pill`) или стиль из `style:` (и стиль, из которого он сделан: `style a from b`).
4. Стиль с именем вида: `style card`, `style btn`.
5. Стекло по умолчанию.

Вещь внутри карточки ничего не берёт у карточки сама: если нужно — `from:` или `style:`.

## Логика в .tb

```
use ui
use view

func main()
    window_sharp()
    try window_open(820, 520, "Окно из .tbs")
    u = ui.start()
    v = view.file("app.tbs")
    repeat while window_alive()
        ui.frame(u)
        clear_window(u.bg)
        view.screen(u, v, "main")
        if view.pressed(v, "save")
            print(view.text_of(v, "name"))
        ui.end_frame(u)
```

| Слово | Что |
|---|---|
| `view.file("app.tbs")` | прочитать файл (`view.from_text(текст)` — из готового текста) |
| `view.screen(u, v, "main")` | нарисовать экран (экранов в файле может быть несколько) |
| `view.pressed(v, "save")` | кнопку нажали в этом кадре |
| `view.text_of(v, "name")` / `view.put_text(v, "name", "...")` | текст поля |
| `view.is_on(v, "id")` / `view.put_on(v, "id", true)` | переключатель, галочка |
| `view.number_of(v, "id")` / `view.put_number(v, "id", 5)` | ползунок, номер в списке, вкладка |

Поменяли `.tbs` и сохранили — окно перерисуется само (файл перечитывается каждые 30 кадров), а то, что ввели в поля, остаётся.
Ошибку в `.tbs` окно покажет красным, с номером строки, а программа не падает.

Пример: `examples/apps/tbs_demo` (`tb run examples/apps/tbs_demo/main.tb`).
