# Файлы .tbs — разметка и стили окна

В файле `.tbs` описано, **что** стоит в окне и **как выглядит**. **Что делает** программа, пишется в `.tb`.
Читает `.tbs` библиотека `lib/view.tb` (`use view`), а рисует `lib/ui.tb`. Сам язык для этого не менялся.

## Сетка как в Excel

Экран делится на клетки: столбцы называются `A B C D ...` (до `Z`), строки — `1 2 3 ...`.
Вещь стоит в одной клетке (`B2`) или в прямоугольнике клеток (`A1:C2`). Окно растянули — растянулась и сетка.

```
screen main 4x7          // экран main: 4 столбца, 7 строк
    cols 200 * * 120     // ширина столбцов: число точек или * (делят остаток поровну). Можно не писать — все *
    rows 56 40 * * 52    // высота строк так же
    space roomy          // расстояния: tight, normal (так по умолчанию), roomy
```

Если нужно точно: `gap 12` (между клетками) и `pad 20` (от края окна).

## Стили

Как классы в CSS: стиль пишется один раз, а у вещи ставится через точку.

```
style price
    color accent       // цвет: accent ink dim red panel bg raised line faint или #ff8800
    size 22            // размер букв
    font bold          // bold, mono или regular
    align right        // left, center, right
    bg raised          // фон под текстом
    radius 10          // скругление фона (и у card)

screen main 2x2
    text "Итого: 0 сом" B2 .price
```

## Логика в .tb

```
use ui
use view

func main()
    window_sharp()
    try window_open(820, 520, "Окно из .tbs")
    u = ui.start()
    v = view.file("app.tbs")
    repeat while window_alive()
        ui.frame(u)
        clear_window(u.bg)
        view.screen(u, v, "main")
        if view.pressed(v, "save")
            print(view.text_of(v, "name"))
        ui.end_frame(u)
```

| Слово | Что |
|---|---|
| `view.file("app.tbs")` | прочитать файл (`view.from_text(текст)` — из готового текста) |
| `view.screen(u, v, "main")` | нарисовать экран |
| `view.pressed(v, "save")` | кнопку нажали в этом кадре |
| `view.text_of(v, "name")` / `view.put_text(v, "name", "...")` | текст поля |
| `view.is_on(v, "id")` / `view.put_on(v, "id", true)` | переключатель, галочка |
| `view.number_of(v, "id")` / `view.put_number(v, "id", 5)` | ползунок, номер в списке, вкладка |

Ошибку в `.tbs` окно покажет красным, с номером строки, а программа не падает.
